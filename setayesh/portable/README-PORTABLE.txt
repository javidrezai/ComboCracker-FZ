SETAYESH AI - PORTABLE (USB)
============================

This folder is a complete, self-contained copy of Setayesh.
It carries its own Node runtime (node\node.exe) and its own data,
so it runs on ANY Windows PC with NO installation and NO internet.

HOW TO USE
----------
1. Copy this whole folder onto a USB stick.
2. On any Windows PC, open the folder.
3. Double-click  Setayesh.bat
4. Your browser opens at  http://localhost:3000
   (Keep the black window open while you use it.)

FIRST LOGIN
-----------
Username: admin
Password: setayesh123
-> Change the password after the first login (Settings).

YOUR DATA
---------
Accounts, memory, the family board and your API keys are stored in
files that start with ".setayesh-" INSIDE this folder - so they travel
with the USB stick. Nothing is written to the host computer.

CARRY YOUR API KEYS
-------------------
The build does NOT copy your keys by default. If you want the same
keys everywhere, copy your ".setayesh-config" file into this folder too.
Otherwise, just enter the keys once on each copy (Settings).

Tip: keep separate USB copies for yourself and for the kids - each keeps
its own accounts and settings.
