# حلقهٔ عامل (Agent Loop)

قلبِ مغز ستایش. یک چرخهٔ کنترل‌شده:

1. **استدلال** — مدل تصمیم می‌گیرد گام بعد چیست.
2. **کنش** — در صورت نیاز، یک ابزار را صدا می‌زند (`TOOL: نام(ورودی)`).
3. **مشاهده** — نتیجهٔ ابزار به حلقه بازخورد داده می‌شود.
4. **خودتعمیر** — اگر ابزار خطا داد، خطا بازخورد می‌شود تا مدل اصلاح کند.

یک **سقف گام** جلوی حلقهٔ بی‌پایان را می‌گیرد. ابزارها: calc، now، search،
web_search، save_note. → [[شفافیت-و-خودتعمیری]] · [[بازیابی-معنایی]]
