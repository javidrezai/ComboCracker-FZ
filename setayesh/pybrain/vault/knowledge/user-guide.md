# راهنمای استفاده از ستایش

## اجرای سریع
- یک پرسش: `bash setayesh/run.sh "سوال شما"`
- حالت تعاملی: `bash setayesh/run.sh`
- وبهوک + داشبورد وب: `bash setayesh/run.sh --serve` سپس مرورگر → <http://localhost:8787>

## دستورها
- `--dashboard` — به‌روزرسانی داشبورد
- `--transparency` — استدلال کامل آخرین اجرا
- `--files` — لیست فایل‌های والت
- `--model qwen2.5:7b` — تغییر مدل
