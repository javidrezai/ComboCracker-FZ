# خودمیزبانی (Self-hosting)

اجرای همه‌چیز روی سختِ‌افزارِ خودتان به‌جای سرویس‌های ابری — **صفر هزینه، حریمِ کامل**.

- مدل با [[Ollama]] محلی اجرا می‌شود.
- مغز به‌صورت سرویس دائمی (systemd) روی سرور بالا می‌ماند.
- دادهٔ شما (والت [[obsidian]]) هرگز از دستگاه خارج نمی‌شود.

مغز ستایش کاملاً برای خودمیزبانی طراحی شده است. → [[معماری-مغز]] · [[Ollama]]
