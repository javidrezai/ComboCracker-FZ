# Ollama

ابزاری برای اجرای **مدل‌های زبانی محلی** روی سخت‌افزار شخصی، بدون هزینهٔ API.

## دستورهای پایه
- `ollama serve` — راه‌اندازی سرویس.
- `ollama pull qwen2.5:7b` — دانلود مدل.
- `ollama list` — لیست مدل‌های نصب‌شده.

مغز ستایش از طریق `http://localhost:11434` به Ollama وصل می‌شود. → [[درباره-ستایش]]
