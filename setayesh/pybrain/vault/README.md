# 🧠 والت مغز ستایش (حافظهٔ دائمی)

این یک **والت Obsidian** است — مکان دومِ مغز ستایش. مغز سرور (مکان اول) از
طریق پل اتصال git با این والت **همگام** می‌شود.

## باز کردن در Obsidian
Obsidian → *Open folder as vault* → این پوشه را انتخاب کنید.

## ساختار
| پوشه | نقش |
|------|-----|
| `knowledge/` | گراف دانش شما — پایهٔ مغز (مغز فقط می‌خواند) |
| `lessons/` | درس‌های خودآموختهٔ مغز |
| `config/brain-settings.md` | تنظیمات زنده (بدون ری‌استارت) |
| `dashboard/DASHBOARD.md` | داشبورد زندهٔ نقشهٔ مغز |
| `logs/` | گزارش استدلال و خودتعمیریِ هر اجرا |

## اتصال به مغز سرور
مغز سرور قبل از هر اجرا از این مخزن `pull` می‌کند (تا ویرایش‌های شما را بخواند)
و بعد از هر اجرا نوشته‌هایش را `push` می‌کند. کافی است در تنظیمات مغز سرور،
آدرس این مخزن را در کلید `vault_remote` بگذارید.

مغز سرور: <https://github.com/javidrezai/ComboCracker-FZ/tree/main/setayesh/brain>
