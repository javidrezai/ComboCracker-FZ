# 📦 مخزن کتابخانه‌های پایتون ستایش

اینجا کتابخانه‌های مهم پایتون **محلی** نصب می‌شوند تا مغز ستایش حتی بدون
اینترنت هم آن‌ها را داشته باشد. مغز موقع اجرا این پوشه را به مسیر ایمپورت
اضافه می‌کند، پس هر چیزی اینجا نصب شود بلافاصله در دسترس مغز است.

## نصب / دانلود
- ویندوز:  `install-libs.bat` را دوبار کلیک کن (یا از داخل ستایش دکمه‌اش را بزن).
- لینوکس/مک:  `bash install-libs.sh`
- از داخل برنامه:  مرکز کنترل ← قابلیت‌ها ← «دانلود کتابخانه‌های پایتون».

فهرست کتابخانه‌ها در `requirements-libs.txt` است؛ می‌توانی ویرایشش کنی.

## دانلود خودکار (بدون کلیک) 🤖
مغز هوشمند است: هر وقت کدی به کتابخانه‌ای نیاز داشته باشد که اینجا نیست،
**خودش** آن را از اینترنت می‌گیرد و **فقط در همین پوشه** نصب می‌کند و ادامه می‌دهد.
پس معمولاً لازم نیست دستی کاری کنی. برای خاموش‌کردن این رفتار: `SETAYESH_AUTO_LIBS=0`.
